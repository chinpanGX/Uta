# ADR 0003: 3Dライブを MVP スコープから外す

## 状況

当初は「育成・ガチャ・3Dライブ」を基礎部分の対象としていた。しかし3Dライブは、サーバー不要でクライアントが Timeline を再生するだけの構成になる見込みで、本プロジェクトの狙い（サーバー権威の縦切り）の検証にあまり寄与しない。

## 決定

- 3Dライブは MVP の対象外とし、[systems/live.md](../systems/live.md) は `deferred`（保留）扱いにする
- MVP は「ガチャ → 編成 → プロデュース → 報酬」の縦切りとする
- 画面（ワイヤー）とカードのロジックを、プロデュースの仕様として先に固める

## 理由

- サーバー権威・MagicOnion・永続化・マスタ配信といった技術検証の価値は、育成とガチャに集中している
- 3Dライブは素材（楽曲・モデル・モーション）の調達コストが大きく、IP方針（[ADR 0001](0001-ip-policy.md)）の観点でもリスクが高い

## 検討した代替案

- 案A: 3Dライブを簡易版（固定カメラ・1曲）で残す。MVP では見送り、再開時の選択肢とする
- 案B: 現状維持。素材調達が先に詰まる恐れがあるため不採用

## 影響・リスク

- [CLAUDE.md](../../../CLAUDE.md) と `docs/project-instructions.md` の目的欄を更新済み。**Claude Project の Custom instructions / 説明文には「3Dライブ」が残っているため、手動で修正が必要**
- 「ライブ → 報酬」「育成結果 → ライブ」の接続が不要になり、仕様が単純になる

## 見直す条件

- 育成とガチャの縦切りが実機で通り、演出面の検証に着手したくなったとき
