# ガチャ

## 目的

排出テーブルに基づく抽選をサーバーで行い、結果を所持品へ反映する基礎部分を実装する。

## 完了条件（基礎部分）

- [ ] 単発／複数連の抽選がサーバーで実行される
- [ ] 排出テーブル（マスタデータ）から抽選できる
- [ ] 天井（一定回数での確定排出）が動く
- [ ] 抽選結果と所持品の更新が1トランザクションで整合する
- [ ] 抽選履歴が保存される

## 決まっていること

- 抽選・所持品更新はすべてサーバー（サーバー権威）
- クライアントは結果の表示のみ

## 未決事項

- レアリティ構成と排出率
- 天井の仕様（回数、引き継ぎ範囲）
- ガチャ消費アイテムの扱い（課金通貨は扱わないか、疑似通貨のみか）
- 重複排出時の処理
- DB（基盤の推奨は PostgreSQL + Npgsql + Dapper、未確定。[server-foundation](../architecture/server-foundation.md)）とトランザクション設計
- 排出率表示の方針

## 方針メモ（推測）

- 本プロジェクトは技術検証が目的のため、実課金は扱わず、疑似通貨のみとするのが無難（要決定）。
