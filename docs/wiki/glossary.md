# 用語集

プロジェクト内の用語はここで定義する。既存作品固有の名称は使わず、Uta 独自の名称を定義すること。

| 用語 | 定義 | 備考 |
|---|---|---|
| Uta | 本プロジェクトの名称 | |
| プロデュース | 育成モード。複数ターンの行動選択でパラメータを伸ばし、最後に評価を受ける | 名称は仮。オリジナル名を決める |
| ガチャ | 排出テーブルに基づくサーバー抽選 | |
| ライブ | 3D演出で楽曲を再生するパート | 保留中（MVP対象外、[ADR 0003](decisions/0003-defer-3d-live.md)） |
| マスタデータ | 静的な設定データ（排出テーブル、カード定義など） | |
| サーバー権威 | 計算・抽選・所持品更新をすべてサーバーが行う方針 | |
| ADR | Architecture Decision Record。技術選定・方針変更の理由を1件1ファイルで残す記録 | `decisions/` に置く。確定後は書き換えず、変更時は superseded にして新規作成 |
| MVP | 最小限の動作範囲。ガチャ→編成→プロデュース→報酬を通す | [game-spec](overview/game-spec.md) |
| 体力 | プロデュース中にカード使用で消費する資源 | 仮。最大40 |
| デッキ / 手札 | 編成したカード10枚 / 毎ターン引く3枚 | 仮 |
| 縦切り | 各層を貫く最小の動作確認（Vertical Slice） | |
