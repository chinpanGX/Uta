# 画面ワイヤー(叩き台)

[プロデュース](../systems/produce.md)・[カードロジック](../systems/lesson-card.md)・[育成アイドル・サポートカード](../systems/idol-support.md)・[ガチャ](../systems/gacha.md)の仕様から起こした、全画面の見た目の叩き台。

画面の一覧・遷移・層の構成・通信の扱いは [screen-design.md](../architecture/screen-design.md) が正。このページは各画面に何をどう並べるかだけを扱う。

> **レイアウト・ボタン配置・文言は叩き台(推測・仮置き)**。名称は仮称([glossary](../glossary.md) の「置き換え対象の仮称」を含む)。ワイヤー内の数値はすべて例で、仕様の値と食い違う場合は仕様が正。

## 共通の方針

決まっていること:

- 画面は縦向き、uGUI + UnityScreenNavigator で作る。Windows は縦長のウィンドウ([ADR 0009](../decisions/0009-client-stack.md))
- 予想値・使用可否は Shared.Domain で出す表示専用の値。確定値はサーバー応答で更新する。乱数が絡む結果(ドローなど)は予測しない([ADR 0008](../decisions/0008-shared-domain-and-onion.md)、screen-design 6章)
- 通信中は入力を受け付けない表示(ブロッカー)を出す(screen-design 5章)

10/25 の叩き台から引き継ぐ操作の方針:

- カードをタップ → 詳細(効果・予想上昇値)を表示 → 「使用」で確定する
- 払えないカード・条件を満たさないカードはグレーアウトする

叩き台として置くこと:

- 取り消せない操作(行動の決定、カードの除去、再挑戦など)の前に確認ダイアログを出す
- 右上の [≡] はメニュー(デッキ確認、アイテム確認、設定、中断)

## 2. 週の行動選択

```
┌──────────────────────────────┐
│ 週 9 / 16   次: 中間試験まで—  [≡]│
├──────────────────────────────┤
│ 歌唱 ▓▓▓▓▓░░░░░  420 / 1500  │
│ 律動 ▓▓▓░░░░░░░  260         │
│ 表現 ▓▓▓▓░░░░░░  310         │
│ 体力 ▓▓▓▓▓▓░░░░  18 / 30     │
│ 育成pt 145   ドリンク [◆][◆][ ]│
├──────────────────────────────┤
│        [ キャラ表示 ]        │
├──────────────────────────────┤
│ 今週の行動                    │
│ ┌────────────┐┌────────────┐ │
│ │ 授業        ││ 支給        │ │
│ │ パラメータ↑ ││ 育成pt・カード│ │
│ └────────────┘└────────────┘ │
│ ┌────────────┐┌────────────┐ │
│ │ 相談        ││ 休む        │ │
│ │ 交換・強化  ││ 体力70%回復 │ │
│ └────────────┘└────────────┘ │
└──────────────────────────────┘
```

- 選べる行動は週構成のマスタで決まる([produce](../systems/produce.md) 3.1)。
- レッスンの週は、歌唱 / 律動 / 表現の3つのレッスンを並べ、特別レッスンになったものに印を付ける。

```
│ ┌────────┐┌────────┐┌────────┐ │
│ │ 歌唱   ││ 律動 ★ ││ 表現   │ │
│ │ 6ターン││ 特別   ││ 6ターン│ │
│ │目標55  ││目標85  ││目標55  │ │
│ └────────┘└────────┘└────────┘ │
```

- 行動をタップ → 確認ダイアログ(効果の要約)→ 決定。決定後は取り消せない。
- 「休む」は体力が減っていないときはグレーアウト。
- 試験の週は行動を選ばず、そのまま 3 に進む。仕上げの週は、レッスンするパラメータを選んでから 3 に進む([produce](../systems/produce.md) 4.2)。
- [≡] → デッキ確認(所持スキルカード一覧)、育成アイテム一覧、中断。
- 未決: サポートイベントの表示(行動の前後に会話を挟むか、テキスト1行にするか)。

```
┌──────────────────────────────┐
│ 律動レッスン(特別)  残り 4/6 [≡]│
│ 目標 85 ▓▓▓▓▓▓░░░ 62 (P 170) │
├──────────────────────────────┤
│ 体力 18/30  元気 7            │
│ [好調3] [集中4] [消費減2]      │ ← ステータス(タップで説明)
│                              │
│        [ キャラ表示 ]        │
│                              │
│ 山札 8  捨札 5  除外 2   [◆][◆] │ ← 山札などはタップで中身を表示
├──────────────────────────────┤
│ ┌─────┐ ┌─────┐ ┌─────┐       │
│ │消費4│ │消費2│ │体消3│       │
│ │ +23 │ │好調 │ │ ░░░ │       │ ← 払えないカードはグレーアウト
│ │     │ │2ターン│ │     │       │
│ └─────┘ └─────┘ └─────┘       │
│ 使用 1/1           [ スキップ ]│
└──────────────────────────────┘
```

試験のときの上部:

```
│ 中間試験           残り 6/9 [≡]│
│ スコア 1,240   順位 2位          │
│ このターン: 律動 (ボーナス 285%) │
│ 次: 歌 → 律 → 表 → 歌 → 律 → 表 │ ← 残りターンの審査パラメータ
```

カード詳細(カードをタップ):

```
┌──────────────────────────────┐
│ S10 (仮)               R   +  │
│ 消費4 → 実際 2(消費体力減少)  │
│ パラメータ+23(集中2倍)       │
│ ──────────────────────────── │
│ 予想: パラメータ +54          │ ← 表示専用
│ レッスン中1回                 │
│     [ やめる ]   [ 使用 ]     │
└──────────────────────────────┘
```

- 予想値は、Shared.Domain で計算した表示専用の値(Presenter は `Application` のユースケース越しに受け取る)。確定はサーバー応答([lesson-card](../systems/lesson-card.md) 9章、screen-design 6章)。山札の中身は枚数と並べ替えた一覧だけ表示する(並び順は返さない。[produce-domain.md](../architecture/produce-domain.md) 6章)。
- ドリンク [◆] をタップ → 詳細 → 「使う」。ターンも使用数も消費しない。
- スキップ: 確認なしで実行するか、確認を出すかは未決。
- ターン終了時の好印象による上昇、発動予約などは、ログ表示で順に見せる(演出の粒度は未決)。
- [≡] → 山札・捨札・除外の一覧、育成アイテム、ステータスの説明、中断。

## 4. スキルカード獲得

```
┌──────────────────────────────┐
│ スキルカードを1枚獲得          │
├──────────────────────────────┤
│ ┌───────┐ ┌───────┐ ┌───────┐ │
│ │ L07   │ │ L10   │ │ L14 + │ │
│ │ R     │ │ R     │ │ SR    │ │
│ │消費4  │ │消費5  │ │消費4  │ │
│ │+7     │ │好印象 │ │好印象 │ │
│ │好印象+3│ │150%   │ │+5 …   │ │
│ └───────┘ └───────┘ └───────┘ │
│   [除去]    [除去]    [除去]  │
├──────────────────────────────┤
│ 再抽選 [ ↻ 残り2 ]             │
│ デッキ 14枚 [ 確認 ]           │
│ [ 受け取らない ]  [ 獲得する ]  │
└──────────────────────────────┘
```

- カードを選ぶ → 「獲得する」で確定。強化済み(+)のカードは強化版の性能を表示する。
- 除去: 押すとそのカードが消え、そのプロデュース中は出なくなる(確認ダイアログあり)。除去の残り回数が0なら非表示。
- 再抽選: 3枚まとめて引き直す。巻き戻しはできない。
- 受け取らない: 確認ダイアログの後、何も獲得せずに進む([produce-domain.md](../architecture/produce-domain.md) 5章 の操作)。

## 5. 授業・おでかけ・支給

授業とおでかけは「3択イベント」として同じ画面を使う。

```
┌──────────────────────────────┐
│ 授業                    週 9   │
├──────────────────────────────┤
│        [ イベント画像 ]        │
│  (イベントの短い文章)          │
├──────────────────────────────┤
│ ┌──────────────────────────┐ │
│ │ 体力8:  表現 +80 / カード1枚│ │
│ └──────────────────────────┘ │
│ ┌──────────────────────────┐ │
│ │ 体力4:  歌唱 +55 / カード1枚│ │
│ └──────────────────────────┘ │
│ ┌──────────────────────────┐ │
│ │ コストなし: 律動 +30 / カード│ │
│ └──────────────────────────┘ │
└──────────────────────────────┘
```

- 払えない選択肢(体力・育成pt不足)はグレーアウト。
- 確率で結果が変わる選択肢(中級11週など)は「40%で+110 / 60%で+40」と表示する。
- 選択 → 結果表示(上がった値、手に入れたもの)→ カード獲得がある場合は 4 へ。
- おでかけは、各選択肢に「体力回復 40%」「ドリンク選択」「カード強化」などを並べる。コストは育成pt または 不調カード1枚。
- 支給は選択肢がないので、結果表示(育成pt、ドリンク)→ 4 だけ。

## 6. 相談

```
┌──────────────────────────────┐
│ ＜ 相談          育成pt 145   │
├──────────────────────────────┤
│ [ カード ] [ ドリンク ] [ 強化 ] [ 削除 ]│ ← タブ
├──────────────────────────────┤
│ ┌───────┐ ┌───────┐           │
│ │ S08   │ │ S13   │           │
│ │ 80pt  │ │ 150pt │           │
│ └───────┘ └───────┘           │
│ ┌───────┐ ┌───────┐           │
│ │ S07   │ │ S14   │           │

│ └───────┘ └───────┘           │
```

- カード・ドリンクのタブ: 4種ずつ。1つは30%引き。交換済みは「交換済み」。ドリンクの所持が3つのときは、捨てるドリンクを選ばせる。

- 「相談を終える」で 2 に戻る(週が進む)。

## 7. 試験結果

```
┌──────────────────────────────┐
│          中間試験 結果          │
├──────────────────────────────┤
│  1位  ライバルA     1,440      │
│  2位  あなた        1,388  ◀  │
│  3位  ライバルB     1,170      │
│  4位  ライバルC       900      │
│  ……                          │
├──────────────────────────────┤
│ 合格! 報酬                    │
│ 全パラメータ +10   育成pt +100  │
│ 育成アイテムを1つ獲得          │
├──────────────────────────────┤
│ [ 再挑戦 (残り2) ]   [ 次へ ]  │
└──────────────────────────────┘
```

- 再挑戦: 確認ダイアログ → 試験の最初からやり直す。残り回数は中間・最終の合計で3回。山札の並びは前回と変わる([produce-domain.md](../architecture/produce-domain.md) 3章)。
- 再挑戦は、体力・デッキ・ドリンクなどを試験の開始直前の状態に戻してやり直す(produce.md 5.1.1)。
- 4位以下のときは「次へ」の代わりに「再挑戦」か「プロデュース終了」。プロデュース終了でも最終評価(8.)へ進み、評価と報酬が出る(produce.md 5.1.1)。再挑戦が残っていなければ「再挑戦」は出さない。
- 中間試験の合格時は、育成アイテムの選択(または獲得)画面を挟む(選択式かは未決)。
- 最終試験の後は 8 へ。
