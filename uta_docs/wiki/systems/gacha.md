# ガチャ

## 目的

排出テーブルに基づく抽選をサーバーで行い、結果を所持品へ反映する基礎部分を実装する。排出されるのは [育成アイドルとサポートカード](idol-support.md)。

参考作品の構造を調査して決めた。名称は Uta の仮称([ADR 0001](../decisions/0001-ip-policy.md))。

凡例: **[確認]** 参考作品で裏取りした構造・数値 / **[決定]** Uta で決めたこと / **[Uta案]** 提案

## 完了条件(基礎部分)

- [ ] 単発 / 10連の抽選がサーバーで実行される
- [ ] 排出テーブル(マスタデータ)から抽選できる
- [ ] 天井(交換pt)が動く
- [ ] 抽選結果と所持品の更新が1トランザクションで整合する
- [ ] 抽選履歴が保存される

## 決まっていること

- 抽選・所持品更新はすべてサーバー(サーバー権威)。クライアントは結果の表示のみ
- **課金は実装しない。ガチャ通貨は無償の1種類だけ**。有償・無償の区別や決済まわりの処理は作らない [決定]

---

## 1. 種類

| 種類 | 内容 |
|---|---|
| 常設ガチャ | 恒常のガチャ。ラインナップは不定期に更新 [確認] |
| ピックアップガチャ | 新しい育成アイドル・サポートカードがピックアップされる [確認] |
| 限定ガチャ | その種類でしか出ないカードがある [確認] |

[Uta案] 初期実装は常設ガチャとピックアップガチャの2種類だけ。

## 2. 価格

- 単発: ガチャ通貨250。10連: 2,500(SR以上1枚確定)。[確認]
- 育成アイドルとサポートカードは同じガチャから出る。[確認]
- [Uta案] 1日1回だけ、ガチャ通貨60で引ける割引単発を置く(参考作品では有償通貨限定の枠)。

## 3. 排出率 [確認]

| | SSR | SR | R | 合計 |
|---|---|---|---|---|
| 育成アイドル | 2.0% | 6.8% | 31.2% | 40.0% |
| サポートカード | 3.0% | 10.2% | 46.8% | 60.0% |
| 合計 | 5.0% | 17.0% | 78.0% | 100% |

ピックアップ(全体の排出率の内数):

| | 確率 |
|---|---|
| ピックアップ育成アイドル(SSR) | 0.75% |
| ピックアップサポートカード(SSR) | 1.0% |
| ピックアップサポートカード(SR) | 4.0% |

## 4. 天井(交換pt) [確認]

- 1回引くごとに1pt。200pt でピックアップの SSR 育成アイドル / SSR サポートカードと交換できる。
- 余った交換pt は、ガチャの期間終了後に交換メダルに変換される。
- 常設ガチャにも200pt の交換がある。ピックアップガチャとは別に数え、ラインナップ更新時にリセットされる。

## 5. 重複したとき [確認]

育成アイドル: かけらに変換する。

| レア | かけら |
|---|---|
| SSR | 50 |
| SR | 25 |
| R | 5 |

- かけらは覚醒([idol-support](idol-support.md) 1.6)に使う。
- 余ったかけらは交換メダルに変換できる(SSR 1個=5、SR=2、R=1)。交換メダルはショップでかけらなどと交換する。
- ピックアップの育成アイドルを入手するたびに、おまけでかけら50個がもらえる形式もある。

サポートカード: 重複は上限解放に使う([idol-support](idol-support.md) 2.2)。完凸後は 7章。

## 6. 実行要件・設計上の論点 [Uta案]

| ID | 要件 | 優先度 |
|---|---|---|
| GAC-01 | 常設ガチャとピックアップガチャを引ける(単発・10連) | 必須 |
| GAC-02 | 排出率をマスタで定義でき、画面で確率を表示できる | 必須 |
| GAC-03 | 交換pt による天井 | 必須 |
| GAC-04 | 重複時のかけら変換と、かけらの交換メダル変換 | 必須 |
| GAC-05 | 限定ガチャ | 後回し |

| 論点 | 方針 |
|---|---|
| 抽選結果の記録 | 1回ごとに、何がどの確率テーブルから出たかを保存する |
| 確率の表示と実際の一致 | マスタの排出率から表示と抽選の両方を作り、二重管理にしない |
| 天井と期間 | 交換pt はガチャごとに持ち、期間終了時に交換メダルへ変換するバッチ処理が必要 |

## 7. Uta で決めること(参考作品で未公開)

| 項目 | 案 |
|---|---|
| 10連の確定枠の排出率 | 10枠目だけ、R の確率を SR に振り替える(SSR 5% / SR 95%) |
| 完凸後のサポートカードの重複 | サポート強化pt に変換 |
