# 育成アイドル・サポートカード

[プロデュース](produce.md)の編成に使うカード(育成アイドル、サポートカード)の仕様。入手は [ガチャ](gacha.md)。

参考作品の構造を調査して決めた。名称は Uta の仮称([ADR 0001](../decisions/0001-ip-policy.md))。

凡例: **[確認]** 参考作品で裏取りした構造・数値 / **[決定]** Uta で決めたこと / **[Uta案]** 提案

---

## 1. 育成アイドル

### 1.1 位置づけ [確認]

- プロデュースで育てる対象。アイドル個人と楽曲の組み合わせで1枚のカード。
- 同じアイドルでも楽曲ごとに別のカード。
- レアリティは R / SR / SSR。

### 1.2 ステータス [確認]

| 項目 | 内容 |
|---|---|
| 体力 | 最大体力。トレーニング・覚醒などで増える |
| 初期パラメータ | 歌唱 / 律動 / 表現の初期値 |
| パラメータボーナス | パラメータごとの%。対応するレッスンの終了時に、上がった量 × ボーナス% が**追加で**上がる(小数点以下切り捨て) |
| アビリティ | トレーニング・覚醒で解放される特殊効果(1.6) |
| 固有スキルカード | プロデュース開始時に持っている専用カード |
| 固有育成アイテム | プロデュース開始時に持っている専用アイテム |
| プラン・おすすめ効果 | 感性(好調・集中)/ 理論(好印象・やる気) |

- プランによって、登場するスキルカード・ドリンク・育成アイテムの種類が変わる。共通のものはどのプランでも登場する。

### 1.3 初期デッキ [確認]

9枚。

| 内訳 | 枚数 |
|---|---|
| 全アイドル共通: F01×2、F02×1、F03×2([lesson-card](lesson-card.md) 14章) | 5 |
| 固有スキルカード | 1 |
| おすすめ効果ごとのカード(アクティブ1枚、メンタル2枚) | 3 |

- メンタル2枚は、好調なら S01、集中なら S02、好印象なら L01、やる気なら L03 と考えられる(推定)。
- [Uta案] おすすめ効果ごとの3枚はマスタで定義する。

### 1.4 審査比率

- アイドルごとに固定の、3パラメータの比率。試験のターン割り振りとスコアボーナスに使う([produce](produce.md) 5章)。[確認]
- 参考作品で見られる比率の型(1番 / 2番 / 3番): 40/33/27、45/40/15、50/30/20、60/23/17。[確認]
- Uta のアイドルの比率は独自に決め、マスタで持つ。[決定]

### 1.5 トレーニング(段階強化) [確認]

育成素材とゴールドを使う。6段階。

| 段階 | 主な強化内容 |
|---|---|
| 1 | 最大体力 または パラメータ |
| 2 | アビリティ解放 |
| 3 | 固有スキルカードの強化 |
| 4 | パラメータ |
| 5 | 最大体力 |
| 6 | アビリティ強化 |

必要素材(SSR):

| 段階 | 素材1 | 素材2 | 素材3(プラン別2種、各) | 素材4 | ゴールド |
|---|---|---|---|---|---|
| 1 | 300 | - | - | - | 5,000 |
| 2 | 700 | 250 | - | - | 10,000 |
| 3 | 1,200 | 750 | 30 | - | 30,000 |
| 4 | 2,400 | 1,250 | 150 | 1 | 50,000 |
| 5 | 3,600 | 2,000 | 300 | 2 | 100,000 |
| 6 | 4,600 | 2,500 | 600 | 5 | 150,000 |

- SR は SSR の0.6倍、R は0.4倍(素材4を除く)。素材4は SR で段階5に1、段階6に2、R は不要。

### 1.6 覚醒 [確認]

同じアイドルの「かけら」を使う。4段階。かけらはガチャの重複などで手に入る。

| 段階 | 主な強化内容 | SSR / SR | R |
|---|---|---|---|
| 1 | 2つ目のアビリティ解放 | 50 | 25 |
| 2 | 固有育成アイテムの強化 | 100 | 50 |
| 3 | パラメータボーナス強化 | 150 | 75 |
| 4 | 最大体力、3つ目のアビリティ解放 | 200 | 100 |

### 1.7 アビリティ

| 枠 | 効果 | 解放 |
|---|---|---|
| 1 | 全特別レッスン発生率+5%(段階6で+10%) | トレーニング2、トレーニング6で強化 |
| 2 | スキルカード再抽選回数+1(覚醒4で+2) | 覚醒1、覚醒4で強化 |

[Uta案] 初期実装はこの1パターンだけにする。

### 1.8 入手 [確認]

- 基本はガチャ。未所持のアイドルのかけらを100個集めると解放できる(SSR)。
- ゲーム開始時に、全アイドルの R を1人ずつ所持している。
- 最初のプロデュースで、SSR を1人選んで獲得できる。

### 1.9 対象外

- 別衣装・別楽曲のバリエーション、トレーニング7段階目、カードの見た目変更

## 2. サポートカード

### 2.1 位置づけ [確認]

- プロデュースに6枚編成する(自分のカード5枚+レンタル1枚)。
- レアリティは R / SR / SSR。
- タイプは 歌唱 / 律動 / 表現 / アシスト の4種。アシストは体力回復や相談の割引など特殊な能力。
- プラン区分(感性 / 理論 / 共通)を持つ。

### 2.2 レベルと上限解放 [確認]

| レア | 上限解放0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| R | 20 | 25 | 30 | 35 | 40 |
| SR | 30 | 35 | 40 | 45 | 50 |
| SSR | 40 | 45 | 50 | 55 | 60 |

- レベル上げには「サポート強化pt」と「ゴールド」を使う [決定。2026-10-31]。強化pt の最大レベルまでの累計は R 30,360 / SR 79,680 / SSR 207,700 [確認]。レベルごとの必要量(強化pt・ゴールド)はレアリティごとにマスタで持つ。ゴールドの量は実装するときに仮の値を置く([produce.md](produce.md) 6.1)。
- 完凸(上限解放4回)には同じカードが5枚必要。上限解放に通貨や強化ptは要らない。
- 完凸後の重複 → 3章(Uta で決める)

### 2.2.1 所持の持ち方と上限解放の操作 [決定。2026-10-31]

- 所持しているサポートカードは、**1枚ずつ ULID(所持ID)で持つ**。ガチャで引くたびに1行増える。レベルと上限解放回数は所持IDごとに持つ([api-design.md](../architecture/api-design.md) 3章)
- 上限解放は**手動**。プレイヤーが「解放するカード」と「素材にするカード」(同じカードIDの別の所持ID)を1枚ずつ選び、`LimitBreakAsync` で確定する。素材にしたカードは消え、解放するカードの上限解放回数が1増える
  - 素材のレベルに使った強化pt・ゴールドは戻らない。画面で素材のレベルが1より大きいときは確認ダイアログに出す
  - 上限解放4回のカードはそれ以上解放できない(`SUPPORT_MAX_LIMIT_BREAK`)。素材が解放するカードと同じ所持ID、別のカードID、他人の所持なら拒否する
  - 進行中のプロデュースに編成している所持IDも、解放・素材にできる。プロデュースは開始時の性能の写しを使うので、結果は変わらない([produce.md](produce.md) 10.5)
- 完凸後の重複は、ガチャで引いた時点で変換する: 同じカードIDで上限解放4回の所持IDを1枚でも持っていれば、行を増やさずサポート強化pt に変換する(`DrawAsync` のトランザクション内。量は3章)。持っていなければ、上限解放の回数にかかわらず1行増やす
- 編成(2.6・[produce.md](produce.md))では所持IDを選ぶ。同じカードIDは1つの編成に1枚まで

### 2.3 サポートアビリティ [確認]

6枠。レベルで解放・強化される。

| 枠 | 解放レベル(R / SR・SSR) | 内容の傾向 |
|---|---|---|
| 1 | 1 / 1 | 初期パラメータ・パラメータボーナス・最大体力など開始時の効果 |
| 2 | 1 / 1 | カードごとに異なる |
| 3 | 2 / 2 | 全カード共通:「このカードのスキルカードサポート発生率を増加」 |
| 4 | 5 / 5 | カードごとに異なる |
| 5 | 10 / 10 | カードごとに異なる |
| 6 | 21 / 25 | 全カード共通:「このカードのサポートイベントによる上昇量を増加」 |

主な種類(SSR の最大値):

| 種類 | 例 |
|---|---|
| 初期ステータス | 初期パラメータ+65、パラメータボーナス+8.5%、最大体力+9、初期育成pt+40、特別レッスン発生率+28% |
| レッスン終了時 | パラメータ+6、特別レッスン終了時パラメータ+17、特別レッスン終了時体力回復+7 |
| スキルカード | アクティブ/メンタル獲得時パラメータ+3、強化時+9、削除時+11 |
| 行動選択時 | 相談+18、おでかけ終了時+15、支給+17、休む+22、授業終了時+7 |
| 試験終了時 | パラメータ+22(プロデュース中2回) |

- サポートアビリティと育成アイテムの発動タイミングが同じ場合、サポートアビリティが先。

### 2.4 サポートイベント [確認]

- SSR は3つ、SR・R は2つ。1つ目は初期、2つ目は Lv20、3つ目は Lv40 で解放。
- SR 以上の1つ目は、専用のスキルカードか育成アイテムの獲得。週の行動を選んだ後、行動が始まる**前**に発生する。
- 2つ目以降は行動の**後**に発生する。

| 効果 | R | SR | SSR |
|---|---|---|---|
| パラメータ上昇 | 10 | 15 | 20 |
| 体力回復 | - | - | 7 |
| 育成pt | 10 | 25 | - |

- 発生確率 → 3章(Uta で決める)

### 2.5 スキルカードサポート

- レッスン・試験中に確率で発生し、手札のカード1枚をそのターンだけ強化する。最大3段階。[確認]
- カードごとに発動するレッスン・ターンの種類が決まっていて、確率は大・中・小の3段階。[確認]
- [Uta案] 2段階目以上の強化版の性能は定義が無いため、初期実装では「そのターンだけレッスン中強化(+)にする」効果として扱う。

### 2.6 レンタル枠 [決定]

参考作品は他プレイヤーのカードを借りるが、Uta ではサーバーのマスタから貸し出す。

- レンタル候補はマスタで定義する(カード、レベル、上限解放回数)。
- 編成画面で、サーバーが候補一覧を返し、プレイヤーが1枚選ぶ。
- 性能はサーバー側で確定させる。クライアントから送られた性能は信用しない。
- 他プレイヤーのカードは借りない(ソーシャル機能は作らない)。

## 3. Uta で決めること(参考作品で未公開)

| 項目 | 案 |
|---|---|
| 完凸後のサポートカードの重複 | サポート強化pt に変換(R / SR / SSR で量を変える) |
| サポートイベントの発生確率 | イベントごとに%をマスタで持つ。初期値は一律の仮の値 |
| スキルカードサポートの発生確率 | 大・中・小に%を割り当ててマスタで持つ(例: 大30% / 中20% / 小10%) |

## 4. 実行要件(ドラフト)[Uta案]

| ID | 要件 | 優先度 |
|---|---|---|
| IDL-01 | 育成アイドルのマスタ(ステータス、プラン、おすすめ効果、審査比率、固有カード・アイテム)を定義できる | 必須 |
| IDL-02 | トレーニング6段階と覚醒4段階で、ステータス・アビリティ・固有カードが変化する | 必須 |
| IDL-03 | パラメータボーナスがレッスン終了時に適用される | 必須 |
| IDL-04 | プロデュース開始時に、おすすめ効果に応じた初期デッキが作られる | 必須 |
| SUP-01 | サポートカードのマスタ(タイプ、プラン、アビリティ6枠、イベント)を定義できる | 必須 |
| SUP-02 | レベル上げと上限解放ができる | 必須 |
| SUP-03 | サポートアビリティがプロデュース中のトリガーで発動する | 必須 |
| SUP-04 | サポートイベントが確率で発生する | 次点 |
| SUP-05 | スキルカードサポートがレッスン中に発生する | 次点 |
| SUP-06 | レンタル枠(2.6) | 必須 |
