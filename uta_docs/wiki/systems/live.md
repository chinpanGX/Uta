# 3Dライブ

> **保留中（MVP対象外）**: [ADR 0003](../decisions/0003-defer-3d-live.md)（accepted）で、クライアントが Timeline を再生するだけの構成になるため MVP から外す方向。再開時にこのページを更新する。

## 目的

楽曲再生・カメラワーク・モーションが同期した3D演出の基礎部分を、クライアント単体で成立させる。

## 完了条件（基礎部分）

- [ ] オリジナルのテスト楽曲1曲を再生しながら、演出が同期して動く
- [ ] Timeline + Cinemachine でカメラワークを制御できる
- [ ] キャラクターモーションが楽曲に同期する
- [ ] Windows / Android / iOS 実機で動作し、フレームレート目標を満たす

## 決まっていること

- サーバー不要。クライアント中心で実装する
- 楽曲・キャラクター・モーションはすべてオリジナル、またはライセンス明確な素材のみ（[ADR 0001](../decisions/0001-ip-policy.md)）

## 未決事項

- 演出制御の方式（Timeline のみか、独自シーケンサか）
- キャラクターモデルの調達方法
- 楽曲の調達方法（自作／ライセンス素材）
- フレームレートと画質のターゲット（モバイル／PC別）
- アセット配信（Addressables）の使用範囲
- ライブ結果とプロデュースの接続方法
