# ADR 0016: ゲームシステムの数値は参考作品の値を使う

## 状況

[ADR 0015](0015-reference-card-values.md) は、[ADR 0001](0001-ip-policy.md) の「抽出データを入れない」の例外を、初期カードセットの数値に限って作った。同じ ADR の「影響・リスク」で、produce.md・gacha.md・idol-support.md も参考作品の数値（週構成、排出率、強化量など。[確認] の印）を初期値として載せていて、それらが例外に含まれるかは決めていない、と書いた。

2026-10-31 の設計書の再レビューで、これらのページが参考作品の数値を「マスタの初期値として使う」と決定済みのように書いていて、ADR と食い違っていると指摘された（gacha.md・idol-support.md で Critical）。

## 決定

- **ゲームシステムの数値は、参考作品の値をそのまま使ってよい**（ユーザーの判断。2026-10-31）。対象は、カードの数値（ADR 0015 の範囲）に加えて、次のもの:
  - 週構成・行動・レッスン・試験の値（ターン数、目標、上昇量、順位報酬、評価の式と区切りなど。produce.md）
  - ガチャの価格・排出率・天井・重複の変換量（gacha.md）
  - 育成アイドル・サポートカードの強化量・必要量・上限・アビリティやイベントの値（idol-support.md）
  - レッスンのルールの値（毎ターンのドロー枚数、ステータスの倍率など。lesson-card.md）
- この ADR は ADR 0015 を置き換える（ADR 0015 の決定はこの ADR に含まれる）。ADR 0001 のうち「抽出データを入れない」は、ゲームシステムの数値に限ってこの ADR が置き換える
- ADR 0001 のそれ以外は有効: キャラクター・名称・楽曲・UI 素材・ロゴ・世界観・シナリオ・カードの名前やテキストや絵はオリジナルにする。ドキュメント・コード・コミットメッセージには作品名を書かない（「参考作品」と書く）
- 参考作品の値は「マスタの初期値」で、バランス調整で変えてよい

## 理由

- ADR 0015 と同じ。個人の技術検証で商用公開は非目標。バランスの取れた数値を最初から持てるので、ゲームとして成り立つかの検証を早く始められる
- 数値の一部だけを Uta 独自にしても、残りの数値と釣り合わなくなり、調整の手間が増える
- ページごとに例外を書くより、1 つの ADR で範囲を決めたほうが、ADR と仕様が食い違わない

## 検討した代替案

- カードの数値だけを例外にし、ほかは Uta 独自の仮の値にする（ADR 0015 のまま）: ADR 0001 に近いが、週構成・排出率・強化量を作り直す手間がかかり、カードの数値と釣り合わない
- ページごとに例外を書く: ADR と仕様が食い違ったまま残る（今回の指摘の原因）

## 影響・リスク

- 公開・共有するときは、この判断を見直す必要がある（ADR 0001・0015 と同じ。法的な判断は専門家に確認する。筆者（Claude）には判断できない）
- 仕様ページの [確認] の印の値は、この ADR を根拠にマスタの初期値として使ってよい。各ページの「数値は参考作品の値」という記述はこの ADR へリンクする

## 見直す条件

公開・配布の形態を決めるとき。
