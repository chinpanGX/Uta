# ADR 0015: 初期カードセットの数値は参考作品の値を使う

> 注記（2026-10-31）: [ADR 0016](0016-reference-game-values.md) で置き換えた（範囲をゲームシステムの数値全般に広げた）。この ADR の決定は ADR 0016 に含まれる。

## 状況

[ADR 0001](0001-ip-policy.md) は「既存作品の名称・素材・スクリーンショット・**抽出データ**を、コード、ドキュメント、アセットに入れない」と決めている。

一方、[lesson-card.md](../systems/lesson-card.md) 14章の初期カードセット（37 枚）は、コスト・効果量・強化後の値を参考作品の値のまま載せている。同じ値は `shared/Uta.Domain.Tests` のテストのカード定義（`Phase1Cards`）にも入っている。2026-10-31 の設計書レビュー（lesson-card.md の I15）で、これが ADR 0001 の「抽出データ」に当たるかの判断が要ると指摘された。代案は、レアリティ × 種別ごとの規則で Uta 独自の値を作り直すことだった。

## 決定

- **初期カードセットの数値（コスト、効果量、強化後の値、使用条件の値）は、参考作品の値をそのまま使う**（ユーザーの判断。2026-10-31）。対象は lesson-card.md 14章と、その値を写したテストのカード定義・マスタの CSV
- ADR 0001 のうち「抽出データを入れない」の部分を、上の数値に限ってこの ADR が置き換える。ADR 0001 のそれ以外（構造だけを模倣する、名称・素材・キャラクター・楽曲・UI・世界観・シナリオはオリジナルにする、作品名を書かない）は有効
- カードの**名前・テキスト・絵**は引き続きオリジナルにする。カードは記号（F01 など）で表し、表示名は Uta 独自の名称を付ける（lesson-card.md 未決事項）
- ドキュメント・コード・コミットメッセージには作品名を書かない（「参考作品」と書く）

## 理由

- 個人の技術検証のプロジェクトで、商用公開は非目標（[game-spec.md](../overview/game-spec.md)）。バランスの取れた数値を最初から持てるので、ゲームとして成り立つかの検証を早く始められる
- カードの数値を作り直すと、テストの期待値もすべて作り直しになる。その手間に対して、技術検証の目的では得るものが少ない
- 数値は表現（名前・テキスト・絵）と切り離されている。表現はオリジナルにする方針を変えない

## 検討した代替案

- レアリティ × 種別ごとの規則（消費 1 あたりパラメータ +N、強化で +α）で Uta 独自の値を作る（レビューの提案）: ADR 0001 と矛盾しないが、値とテストの期待値を作り直す手間がかかり、バランスも一から調整になる
- ADR 0001 を書き換えずに、仕様ページに例外として書くだけにする: ADR と仕様が食い違ったまま残り、後で読む人（LLM を含む）が ADR 0001 に従って値を作り直しかねない

## 影響・リスク

- 公開・共有するときは、この判断を見直す必要がある（ADR 0001 の「影響・リスク」と同じく、法的な判断は専門家に確認する）。数値の組み合わせが調整済みのコンテンツとして保護の対象になりうるかは、筆者（Claude）には判断できない
- この ADR の対象はカードの数値だけ。produce.md・gacha.md・idol-support.md も、週構成・排出率・強化量などの数値を参考作品の値の初期値として載せている（[確認] の印）。それらがこの例外に含まれるかは決めていない（下の「見直す条件」）

## 見直す条件

- 公開・配布の形態を決めるとき（ADR 0001 と同じ）
- カード以外の数値（週構成・排出率・強化量など）の扱いを決めるとき。含めるなら、この ADR を置き換える新しい ADR で範囲を広げる
