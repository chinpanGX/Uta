# uta_docs/plans

実装計画の置き場。仕様（`uta_docs/wiki/`）が「何を作るか」を決め、実装計画は「どのファイルに何を書くか」を決める。実装は、この計画をもとに Sonnet のサブエージェントが行う（[ADR 0017](../wiki/decisions/0017-spec-design-plan-stages.md)、proposed）。

## 計画を書くとき

次のどれかに当たる変更は、実装の前に計画を書く。

- 複数のレイヤー（client / server / shared / masterdata）にまたがる
- 新しい型・サービスの IF・DTO・マスタの表・DB のテーブルを足す、または形を変える
- 実装を Sonnet のサブエージェントに任せる

1 ファイルで済む修正、誤字、設定の値の変更などは計画を書かずに直してよい。

## ファイル

- 名前: `YYYY-MM-DD-<件名>.md`（件名は英小文字とハイフン。例: `2026-11-01-gacha-draw.md`）
- レビューで何度でも書き換えてよい（raw と違う）。実装が終わったら `status: done` にして残す

先頭に frontmatter を置く:

```
---
title: 実装計画: <件名>
status: draft | ready | in-progress | done
updated: YYYY-MM-DD
spec: <仕様ページへの相対パス（複数なら並べる）>
---
```

- `draft`: 書いている途中、またはレビューで直している
- `ready`: 設計書のレビュー（`requesting-design-review`）を通った。実装に渡してよい
- `in-progress`: 実装している
- `done`: 実装が終わり、仕様とのズレを wiki に反映した

## 書くこと

基準は **Zero-Decision Rule**: この計画と、リンクした仕様・ADR だけを読んだ実装担当（Sonnet）が、**設計判断を一つもせずに**実装できること。DB の形、API のシグネチャ、依存の追加、新しい境界の扱いを、実装担当に選ばせない。
（egm の Implementation Readiness Standard による。[google/elephant-goldfish-model](https://github.com/google/elephant-goldfish-model)、Apache-2.0）

### 1. 目的と前提

- 何を実装するか（1〜3 文）。仕様は書き写さず、仕様ページの節へリンクする
- 関係する ADR
- この計画で**決めないこと**（範囲外。後の計画に回すもの）

### 2. 触るファイル

ファイルごとに **作成 / 変更 / 削除** を付けて並べる。

| 操作 | パス | 中身 |
|---|---|---|
| 作成 | `shared/Uta.Domain/Gacha/GachaTable.cs` | 排出テーブルの型 |
| 変更 | `server/...` | ... |

（表の行は例）

### 3. 型とシグネチャ

足す・変える型、メソッド、DTO、マスタの列、DB のテーブルを、名前・型・取りうる値まで書く。コードで書いたほうが早いものはコードで書いてよい（C# のバージョンは置き場所のフォルダの `.editorconfig` に合わせる）。

### 4. タスク

実装担当に 1 回で渡す単位に分ける。タスクごとに:

- 触るファイル（2 の表の行）
- 手順（何をどう変えるか。「〜を整える」ではなく「〜に〜を足す」）
- 境界の扱い（0 件、上限、失敗、重複した要求）
- 終わったことの確かめ方（どのテストが通ればよいか）

**各タスクが終わったとき、ビルドとテストが通る状態にする。** 途中で壊れたままのタスクを作らない。

### 5. テスト

足すテストケースを、正常系と境界ごとに並べる（テスト名は `Method_Condition_Result` の形でよい）。実行するコマンドは CLAUDE.md の「ビルド・テスト・実行」にあるものだけを書く。Unity・実機でしか確かめられないものは、そう書く。

### 6. 未決事項

実装に入る前に決める必要があるもの。ここが空になるまで `ready` にしない。

## 実装担当が守ること

- 計画に書かれていない設計判断に出会ったら、自分で決めずに止まり、何が決まっていないかを報告する。計画を直してから続ける
- 計画と違うことをしたくなったら、理由を添えて報告する。黙って変えない
