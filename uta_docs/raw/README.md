# uta_docs/raw

変更しない一次資料の置き場。

- 調査ログ、ライブラリの README 抜粋、検証結果、観察メモなど
- 一度置いたファイルは書き換えない（訂正は新ファイルで）
- ファイル名は `YYYY-MM-DD-件名.md` を推奨
- 既存作品の素材（画像・音源・データ）は置かない（[ADR 0001](../wiki/decisions/0001-ip-policy.md)）

置いた内容は `uta_docs/wiki/` に反映し、`index.md` を更新する。変更の記録はコミットメッセージに書く（[ADR 0018](../wiki/decisions/0018-change-log-from-git.md)）。

- [2026-11-01-wiki-log.md](2026-11-01-wiki-log.md) — 2026-11-01 まで wiki に置いていた更新履歴（追記しない）
